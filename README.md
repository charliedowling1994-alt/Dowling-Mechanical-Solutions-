# DMS Engineering LTD Website

A fixed-layout website for DMS Engineering LTD.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Included Sections

- Hero with precision engineering value proposition
- Services
- Capabilities
- Industries served
- Process
- Testimonials
- About
- Contact form

## Run Locally

1. Open `index.html` in a browser.
2. For live reload, use your preferred local server extension.

## Notes

- Contact form is front-end only and does not submit to a backend.
- Replace business details and testimonials with real company content.
